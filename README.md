### 👋 Introduction

**DevTracker** isn't just another project management tool—it's your team's new command center. Built for speed and designed for focus, it combines the flexibility of Trello with the power of Linear. Say goodbye to clutter and hello to streamlined workflows.

Whether you're managing a solo indie hack or leading a sprint for a growing startup, DevTracker keeps you moving forward.

---

### ✨ Features That Wow

⚡ **Blazing Fast Performance**
Experience **Optimistic UI** updates that make every interaction feel instant. No loading spinners, just speed.

🎨 **Stunning Visuals**
Crafted with a premium aesthetic using **Tailwind CSS**. Dark mode support that looks good in any light.

🔒 **Enterprise-Grade Security**
Powered by **Supabase Auth** and robust **Row Level Security (RLS)**, your data is safe and scoped to your team.

🔄 **Real-Time Sync**
Collaborate without conflicts. Changes happen live across all devices instantly.

📊 **Smart Sprint Management**
Seamlessly organize tasks into sprints, track history, and drag-and-drop your way to productivity.

### 🚀 Getting Started

Ready to ship? Let's get this running locally.

**Prerequisites:** Node.js

1.  **Clone the Magic**
    ```bash
    git clone https://github.com/UsoguiH/DevTracker-.git
    cd DevTracker
    ```

2.  **Install Dependencies**
    ```bash
    npm install
    ```

3.  **Configure Segrets**
    Create a `.env.local` file and add your Supabase keys:
    ```env
    VITE_SUPABASE_URL=your_url_here
    VITE_SUPABASE_ANON_KEY=your_key_here
    ```

4.  **Launch!**
    ```bash
    npm run dev
    ```
